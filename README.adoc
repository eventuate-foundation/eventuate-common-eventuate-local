= Eventuate Common Eventuate Local

image::https://eventuate.io/i/logo.gif[]

This project is part of http://eventuate.io[Eventuate], which is a microservices collaboration platform.

It contains the classes that the Eventuate Local event store and the Eventuate CDC service share to describe the events they read from the database transaction log.

It publishes these artifacts under the group `io.eventuate.common.eventuate.local`:

|===
| Artifact | Package | Contents

| `eventuate-common-eventuate-local`
| `io.eventuate.common.eventuate.local`
| `BinLogEvent`, `BinlogFileOffset` and `PublishedEvent`

| `eventuate-common-eventuate-local-bom`
|
| The BOM for these artifacts
|===

Its version is set in a consumer's `gradle.properties` with the property `eventuateCommonEventuateLocalVersion`.

== Migrating from eventuate-common

This module was previously published by https://github.com/eventuate-foundation/eventuate-common[eventuate-common] under the group `io.eventuate.common`.
The package is unchanged.
The module declares the capability of its old coordinates, so a Gradle build that gets both the old and the new artifact fails with a capability conflict.

The https://github.com/cer/openrewrite-recipes/blob/master/eventuate-common-split/README.adoc[migration guide] lists the new groups, version properties and packages, and describes the OpenRewrite recipe that migrates a consumer.
